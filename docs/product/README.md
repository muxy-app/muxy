# Muxy product model

Muxy is a terminal multiplexer for organizing projects and working in tabs and
split panes. A separate server owns projects and terminal sessions; desktop,
terminal, and paired mobile clients provide views of that work.

These documents define the product's concepts and behavior. Read them in order:

1. [Product model](./product-model.md) — entities, ownership, and project rules.
2. [App model](./app-model.md) — client layouts, navigation, settings, and updates.
3. [Server model](./server-model.md) — session lifetime, attachment, and history.

The [technical design](../tech/README.md) defines how these rules are implemented.
