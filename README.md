## Top level features

- Background sessions
- Remote sessions
- Split panes
- Git worktrees
- Extensions
- Mobile companion apps (iOS & Android)
- AI coding agent integrations
- 490+ themes

## Install

### Homebrew

```bash
brew tap muxy-app/tap
brew install --cask muxy
```

### Manual

Download the latest release from the [releases page](https://github.com/muxy-app/muxy/releases)

### Muxy 2 Beta

Homebrew installs Muxy 1.x. To try Muxy 2, see [Getting started](docs/user-guide/getting-started.md).

For the standalone CLI and server on macOS or Linux, see
[CLI and server installation](docs/user-guide/getting-started.md#cli-and-server-only).
